# 📦 Sistema de Controle de Estoque  

O sistema oferece:

- ✔️ Controle total de produtos  
- ✔️ Gerenciamento seguro de usuários  
- ✔️ Acesso protegido por autenticação  
- ✔️ Dashboard com visão geral do estoque  
- ✔️ Design simples, responsivo e funcional  

---

Tecnologias Utilizadas — *Back-end*

- **Java 21**  
- **Spring Boot 3**  
- **Spring MVC**  
- **Spring Security**  
- **Spring Data JPA**  
- **H2 Database**  
- **Thymeleaf**  

---


Autenticação e Segurança
- Login protegido
- Controle de acesso baseado em função (ROLE_ADMIN e ROLE_USER)
- Página personalizada de acesso negado

 Gestão de Usuários (Admin)
- Criar, listar, editar e excluir usuários
- Apenas administradores têm acesso ao módulo

 Gestão de Produtos
- Cadastro de produtos
- Edição e exclusão
- Listagem com filtros
- Ordenação e busca
- Interface limpa e intuitiva

 Dashboard
- Total de produtos cadastrados  
- Quantidade total em estoque  
- Valor total em estoque  
- Visualização rápida de informações essenciais
